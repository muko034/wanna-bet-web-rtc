# Wanna Bet

Turn-based social betting game. The Host owns authoritative game state; Guests connect directly over WebRTC.

## Commands

- Build: `npm run build`
- Test: `npm test`
- Integration (real browser, starts its own PeerJS server): `npm run test:integration`
- E2E (real browser, starts its own servers): `npm run test:e2e`
