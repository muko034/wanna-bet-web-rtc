# Wanna Bet

Turn-based social betting game. The Host owns authoritative game state; Guests connect directly over WebRTC.

## Commands

- Build: `npm run build`
- Test: `npm test`
- Smoke test (manual, requires local PeerJS server — see `README.md`): `npm run test:smoke`
